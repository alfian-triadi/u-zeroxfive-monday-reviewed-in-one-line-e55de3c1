Entry for the [Monday, Reviewed in One Line](https://make.fun/c/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) competition on [make.fun](https://make.fun). The task: write the funniest one-line review of my own Monday, under 200 characters, and nothing else.

## The entry

> Monday opened with a 9 a.m. meeting to schedule another meeting, an inbox that multiplied overnight, and coffee that tasted like a resignation letter.

**150 characters** (limit: 200).

## How to run

Requires Node 22 or later. No dependencies to install.

```sh
node main.ts
```

This writes the one-line entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set), validates it is 1–200 characters, and verifies the file reads back byte-identical.
